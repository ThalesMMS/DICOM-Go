# Third-party notices

Every file in this module that derives from another project is listed in
[`THIRD_PARTY_PROVENANCE.json`](THIRD_PARTY_PROVENANCE.json) with its upstream
commit, source file, line range, source and artifact SHA-256, license and
distribution class. `go test ./internal/provenance` (part of `make check`)
fails when an artifact, license file or one of the headings below is missing
or changed without updating the manifest. See
[docs/THIRD_PARTY_PROVENANCE.md](docs/THIRD_PARTY_PROVENANCE.md).

Default policy: behavior is implemented independently from the DICOM standard;
reference projects inform strategy. Production code is not copied from DCMTK,
GDCM or VTK. Tables, test vectors and fixtures may be imported with the notices
below.

### ITK — image-to-image similarity metrics

The Mattes mutual information of the `registration` package reproduces the
conventions of ITK's `MattesMutualInformationImageToImageMetricv4` (tag
