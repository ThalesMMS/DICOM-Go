# Interface-local Shape Detection level sets

The separate [research PCA shape prior](PCA_SHAPE_PRIOR.md) adds an explicit
fixed-target reaction to `DenseBand`. Weight zero preserves the base result;
the InterfaceLocal profile described here keeps its existing schedule.

`roi.ShapeDetectionLevelSet` adds an explicit `Evolution: roi.InterfaceLocal` profile for dense supplied edge potentials. `DenseBand` remains zero and preserves the existing solver/defaults. Geodesic, threshold and Canny level sets retain their existing schedule. There is no implicit fallback between profiles.

Default `Initialization: CityBlockSeeds` crossing values use the minimum linearly interpolated face intercept, scaled by `c`, the minimum spacing. This is the L1 distance to a local affine zero plane in index coordinates, consistent with the city-block layer increments. It is not Euclidean normal distance. The explicit InterfaceLocal-only [BoundedFaceNormalSeeds](BOUNDED_FACE_NORMAL_SEEDS.md) option bounds a local physical face-normal seed by that default gauge; it adds no volume-sized buffers. Initial closest-endpoint ties belong to both equally nearest physical samples, independently of storage order or foreground phase; both half-layer endpoints can be active initially. This preserves the interpolated crossing of an affine input plane. The initial tie rule commutes with grid reflections, axis permutations and sign complement. The subsequent half-open phase does not promise full solver duality under sign complement. Adding the tied endpoint can change the observed speed maximum, curvature maximum and RMS because every active sample participates in the same unchanged reductions. A zero-term transition into the persistent half-open phase retains the same crossing. Subsequent membership uses one fixed half-open numerical range `-c/2 < phi <= c/2`. Only anchors supporting the centered derivative footprint receive PDE updates. Membership persists until the updated value leaves that range: an inward demotion promotes adjacent outside samples at `phi+c`; an outward demotion promotes adjacent inside samples at `phi-c`. Candidate changes are staged against the immutable previous field. For an outside target, arriving expansion candidates form their signed minimum; for an inside target, contraction candidates form their signed maximum. This preserves zero arrival when fronts conflict: selecting the smallest absolute value could otherwise erase a candidate that crossed zero. Equal signed candidates give the same value, independently of source order. This zero-envelope rule does not claim exact Euclidean distance for arbitrary unions. Order and uniqueness are deterministic. After a complete reconstruction, numerical anchors without any current crossing are removed before the next PDE. If part of the active set remains, one extra graph rebuild uses the final anchors and an immutable current snapshot. The half-layer bounds make that rebuild sign-preserving, so no stabilization loop is needed. Previous derivative readiness is kept in a spare membership bit during this stage; extra stored projection requires both its original permission and current phase agreement. A distant removal therefore does not re-enable a previously blocked projection. A zero plateau touching negative remains a crossing, and a boundary sample remains a valid partner. Removed orphan offsets do not remain in the next derivative field. RMS still measures the actual anchors updated by the preceding accepted step.

Reconstruction propagates signed graph layers from those anchors: outside values start at `phi_anchor+c*faceDistance`, inside at `phi_anchor-c*faceDistance`. Using the signed anchor avoids the unequal two-sided offsets caused by using its absolute magnitude on both sides. The same bounded heap is used, with positive priorities; the legacy Eikonal reinitializer remains byte-identical to the first candidate. A complete promotion/reconstruction step precedes stopping checks and snapshots. Excessive one-layer jumps refuse nil/error. This independent schedule does not claim to duplicate ITK private status lists.

The new-profile step is `min(hmin/(2D*first), hmin²/(2D*curvature), 1/(sqrt(2D)*first/hmin+2D*curvature/hmin²))`, omitting zero terms; all-zero terms return zero. First is the maximum physical propagation speed and curvature the maximum normalized tangential diffusivity over the active set. The Godunov stencil can retain two unilateral derivatives per axis at an extremum, so Cauchy–Schwarz bounds their coefficient sum by `sqrt(2D)`. The combined guard is conservative for the linearized principal part; it is not a nonlinear convergence theorem. It is global and does not depend on fixture results. The legacy timestep function is untouched. This independent schedule does not reproduce ITK's private sparse-field status transitions or saturated phi values far from the interface. The declared bounded face-normal profile has passed the fixed numerical qualification described below; this does not claim default or full ITK parity.

Use `Input: roi.EdgePotentialImage`, finite `g` in [0,1], positive regular spacing in mm, and at least three samples on each active axis. Two dimensions use one slice. Holes, padding/nonfinite callbacks, intensity-derived input, invalid enums, unknown spacing, and over-budget work return nil/error. A false or nonfinite callback produces `ErrShapeInterfaceDomain`. Invalid profile/sampling combinations fail before callbacks. Input arrays, callback state, masks and options must remain stable for the call. Returned masks own their storage and do not alias caller payloads.

Only InterfaceLocal regularizes the curvature denominator as `q+1e-6`, where `q=|grad(phi)|²` uses physical central derivatives. Its existing Hessian numerator, mean/sum convention and propagation stencil are unchanged. Phi and coordinates both have mm units, so q and the regularization are dimensionless. Scaling both units together preserves this expression; rescaling only phi does not, so gauge invariance is not promised. This regularization belongs to the fixed numerical embedding. It gives zero curvature contribution at a zero gradient and a finite continuous limit near it. It does not regularize the geometric gradient used by interface sampling or alter timestep bounds. DenseBand, geodesic, threshold and Canny callers retain their historical `q>1e-12` cutoff and literal division by q through the zero-regularization facade. The implementation uses its own existing stencil; the denominator is behaviorally informed by public ITK5.4.5.

The negative-inside equation remains `phi_t = -P*g*|grad(phi)| + C*g*kappa*|grad(phi)|`. Phi and RMS have mm units, but the city-block embedding is not exact Euclidean physical distance. Each numerical face step adds the minimum spacing and saturates at `(dimensions+1)*minimumSpacing`; first and mixed PDE derivatives still use each true axis spacing. g is dimensionless, P has length/time and C length-squared/time. Iterations represent adaptive numerical steps, not elapsed clinical or wall time. `MaximumRMSChange` is multiplied by the smallest active spacing. `MeanCurvature` and `SumCurvature` retain their explicit meanings. `GridCentres` is the canonical sampling option. `InterpolatedInterface` reconstructs a zero crossing along the physical central gradient and samples g multilinearly, clamps coordinates to the domain, and uses the centre when the gradient vanishes. It requires InterfaceLocal.

Zero-normal boundary compatibility is explicit. Boundary indices project onto adjacent interior indices. Compatibility uses an immutable field snapshot, including on size-three axes whose next inward neighbour is itself a boundary sample. Production projection also requires the boundary and projected interior to have shared a phase before the accepted step. This eligibility is computed completely from the previous snapshot before that buffer is reused. Initial reconstruction therefore conserves authored foreground signs, including unsupported boundary protrusions, even when no PDE update occurs. A boundary tangential to an evolving planar interface can still move with its interior because their previous phases agreed. Only valid unsaturated layer values whose next inward values are equal in every missing axis can be copied to a boundary sample; otherwise its signed layer value remains. Saturated values carry no normal-derivative information. For PDE and interpolated-potential gradients, eligible boundary samples instead use a virtual copy of the adjacent interior value: previous readiness and current phase agreement must both hold, uniformly over the complete field read by all rates. A current boundary-normal crossing therefore remains an actual sample. First, second and mixed derivatives use the same extension; stored phi and output masks are not overwritten by it. This is first-order zero-normal repetition at the half-face between the boundary sample and its adjacent interior sample, with a local curvature bias in the first interior row; it is not exact quadratic extrapolation or an ITK boundary-status reproduction. It avoids the rate discontinuity caused by selecting a stored projection branch through exact equality. Size-three axes use their only interior sample; corners project all active axes simultaneously. The extension adds no extrapolation weights or retained arrays and no hidden frozen layer. This permits boundary values and signs to change for a transverse planar interface and adds no frozen value, padding or acceptance crop. If active references disappear, the last finite field is preserved because no distance transform can be inferred. Crossings without supported anchors return `LevelSetStopBoundaryActiveExhausted` with `Converged=false`; disappearance of the zero surface instead returns `LevelSetStopEmptyBand`. A global crossing check after every complete accepted step recognizes disappearance even while values remain in the numerical active range, before RMS or stable-mask stopping; it does not remove partial anchors or alter surviving layers. Domain exhaustion is not RMS or clinical convergence. `ReportTouches` reports foreground crop/source contact; `RejectTouches` refuses a contacted or boundary-exhausted result with nil/error. RMS/stable-mask stopping may set Converged; the other reasons do not. Progress is synchronous. Cancellation is polled before reads/allocations and in bounded chunks of active entries, neighbour visits, updates, heap pops and final output. Callback cancellation is observed before publication.

The new profile reserves 224 bytes per cropped voxel plus full source-height row headers, bounded map cardinality, seeds, captured worker records, and the existing conservative Gaussian/EDT allowances. This is a logical array-capacity reservation, not an RSS promise: allocator size classes, runtime map bookkeeping and unreachable GC-retained arrays are outside an exact capacity claim. Finite ceilings remain 16 Mi voxels, 1 GiB logical bytes, 10000 iterations and 64 seeds; zero uses existing defaults, negative or larger ceilings reject. The conservative lifetime ledger charges 183 bytes per voxel for image/edge/phi, status/lists, seeds, old/new heap backing, active/spare/rates/window, promotion staging and exact final RLE. The lazy distance heap charges old/new backing coexistence. Seed initialization uses the opt-in fixed-capacity FastMarching wrapper; queue capacity is N and copied seeds capacity is S. Final output counts runs first and allocates one exact arena; each row uses a full-slice capacity-limited view. Legacy allocation paths remain unchanged.


The original public G2 run remains STOP because its runner compared a float32 getter with a double. An explicitly authorized recovery phase reclassified its existing output 180 without rerun and executed 181..503 once. All 504 public executions are unique; the six original expectations, masks, iterations and RMS match byte for byte. G2 took 16.86407 s, recovery 23.39379 s, calendar elapsed 857.759428 s. These are correctness timings, not performance measurements. Public setting comparisons use exact float32 bits only for ValueType fields, and exact double dt/RMS settings. No tolerance or criterion was relaxed.
